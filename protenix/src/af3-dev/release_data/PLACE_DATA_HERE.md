# Protenix chemical component data goes here

These CCD reference files have been **removed from this archive** to keep it
lightweight. They are publicly downloadable.

## How to obtain

```bash
# run from this directory
wget https://af3-dev.tos-cn-beijing.volces.com/release_data/components.v20240608.cif
wget https://af3-dev.tos-cn-beijing.volces.com/release_data/components.v20240608.cif.rdkit_mol.pkl
```

## Where to place them

The resulting files must live at:

```
protenix/src/af3-dev/release_data/components.v20240608.cif
protenix/src/af3-dev/release_data/components.v20240608.cif.rdkit_mol.pkl
```

See [`../../../README.md`](../../../README.md) → Installation, step 2.
